# CSharp-.NET-Template
A template for C# .NET development in Schools Digital.

## Using the template

Install the package from [nuget.org](https://www.nuget.org/packages/GovUK.Dfe.SchoolsDigitalApp/).

```shell
dotnet new install GovUK.Dfe.SchoolsDigitalApp
```

Now you can instantiate the template. Inside your git repository, run

```shell
dotnet new sd-app --name YourAppName --output .
```

substituting `YourAppName` for the name of your application. The name should be pascal-cased.
